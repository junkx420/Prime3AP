First public beta of **Metroid Prime 3: Corruption for Archipelago** (Wii PAL RM3P01, Dolphin/PrimeHack, Windows).

**Install guide:** [docs/INSTALL.md](https://github.com/junkx420/Prime3AP/blob/main/docs/INSTALL.md)

## Files

| File | |
|---|---|
| `metroidprime3.apworld` | the world (world version 0.3.0), launcher entry, patch file support and the Metroid Prime 3 Client |
| `metroidprime3-example.yaml` | example player YAML (default options) |
| `metroidprime3-tools-win.zip` | patch tools; downloaded automatically on the first patch, only needed for offline installs |
| `wiimms-iso-tools-r8638-src.tar.gz`, `cygwin-3.1.7-1-src.tar.xz` | corresponding source of `wit.exe` (GPL-2.0) and `cygwin1.dll` (LGPL-3.0) in the tools ZIP, unmodified from the official sources; not needed to play |
| `SHA256SUMS.txt` | SHA-256 of the files above |

You need Archipelago 0.6.8 or newer and **your own** Wii PAL disc image (RM3P01). No game files are provided.

## What works

- **Tested end to end:** a 2-player multiworld (Metroid Prime 3 + ChecksFinder) was played to the goal.
- 99 shuffled locations; items of other players show as "Archipelago Item".
- Goal: defeat Dark Samus / **Aurora Unit 313** on Phaaze; the client reports the goal to the server.
- Open the `.apmp3` in the Archipelago Launcher: the patched ISO is built from your ISO (about 40 s, progress window),
  then the client starts.
- **Automatic tool download:** the patch tools are downloaded once from this release and checked against a fixed
  SHA-256 (offline installs: put the tools ZIP into the cache folder, see the install guide).
- Client: sends location checks, gives received items, checks that the running ISO belongs to your slot (seed check),
  and **warns before you enter a Leviathan seed** without the item you need to get out again.

## Known limitations

- **Wii PAL (RM3P01) only**; no NTSC-U/NTSC-J, no Metroid Prime Trilogy.
- **No game-specific options yet:** default starting items, no tricks in the logic, fixed starting location
  (G.F.S. Valhalla, Docking Bay 5).
- **Screw Attack is always on one of the three starting pickups** (needed so every seed can be generated with the
  small start).
- **Received Energy Tanks are empty** until your energy is refilled next (save station or energy pickups).
- **SkyTown Elysia bomb sequence:** doing it in the wrong order can crash the game (seen when collecting only the first
  part of the seed bomb and going back to SkyTown Elysia Main). Do not start it without Seeker Missiles; if it
  happens, reload your save.
- Leviathan cores: enter only with the exit item (Bryyo → Hyper Ball, Elysia → Hyper Missile, Pirate Homeworld →
  Hyper Grapple + Grapple Voltage). The client warns you (`/seedwarn off` turns the warning off).
- **Several location flag blocks per world:** the game keeps more than one copy of a world's pickup flags. The client
  checks all of them and no pickup was lost in testing, but it is not proven yet.
