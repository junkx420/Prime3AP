First public beta of **Metroid Prime 3: Corruption for Archipelago** (Wii PAL RM3P01, Dolphin/PrimeHack, Windows).

**Install guide:** [docs/INSTALL.md](https://github.com/junkx420/Prime3AP/blob/main/docs/INSTALL.md)

## Files

| File | |
|---|---|
| `metroidprime3.apworld` | the world, launcher entry, patch file support and the Metroid Prime 3 Client |
| `Metroid Prime 3 Corruption.yaml` | example player YAML (default options) |
| `metroidprime3-tools-win.zip` | patch tools; downloaded automatically on the first patch, only needed for offline installs |
| `SHA256SUMS.txt` | SHA-256 of the files above |

You need Archipelago 0.6.8 or newer and **your own** Wii PAL disc image (RM3P01). No game files are provided.

## Features

- 99 shuffled locations; items of other players show as "Archipelago Item".
- Open the `.apmp3` in the Archipelago Launcher: the patched ISO is built from your ISO (about 40 s, progress window),
  then the client starts. The patch tools are downloaded once and checked against a fixed SHA-256.
- Client: sends location checks, gives received items, detects the goal (Dark Samus / Aurora Unit 313 on Phaaze),
  checks that the running ISO belongs to your slot, warns before entering a Leviathan seed without its exit item.

## Known limitations

- Wii PAL (RM3P01) only; no NTSC, no Metroid Prime Trilogy.
- Leviathan cores: enter only with the exit item (Bryyo → Hyper Ball, Elysia → Hyper Missile, Pirate Homeworld →
  Hyper Grapple + Grapple Voltage).
- SkyTown Elysia bomb sequence: do not start it without Seeker Missiles (game crash seen in testing).
- The game keeps several copies of a world's location flags; no pickup was lost in testing, but it is not proven yet.
- Received Energy Tanks are not refilled; no game-specific options yet.
